# v3.4.10 - Seamless Agent Adoption Proofs

ContextLattice now ships a cross-profile adoption proof for agent runtimes.

## Highlights

- Added `scripts/agent/agent-adoption-proof-matrix` and global `contextlattice_agent_adoption_proof`.
- The proof runs the live agent lifecycle across configured profiles: bootstrap, context pack, checkpoint, handoff, completion, status, context package, and runtime visibility.
- Each case reports Skills Index evidence, context-package validation, session event counts, graph touches, checkpoint counts, handoff counts, and reference-prompt size.
- Optional provider CLI smoke checks detect installed runner surfaces without requiring paid provider execution, and `--provider-model provider=model` can target a specific model during explicit execution.
- Local compose now mounts the agent contract registry into `gateway-go` so hot-swapped local containers do not run stale session rollup/context-package contracts.

## Verification

```bash
contextlattice_agent_adoption_proof --skip-provider-smoke --pretty
contextlattice_agent_adoption_proof --execute-provider-smoke --provider-smoke-providers codex --provider-model codex=gpt-5.3-codex-spark --pretty
contextlattice_agent_runtime_doctor --pretty
```
