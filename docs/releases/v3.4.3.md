# ContextLattice v3.4.3

Release focus: agent session rollups and prompt-ready context packages.

## Added

- `GET /v1/agents/sessions/{session_id}/rollup` returns a bounded `agent_session_rollup.v1` payload with objective state, source coverage, artifacts, risks, prompt-package readiness, confidence, and recent events.
- `GET /v1/agents/sessions/{session_id}/context-package` returns a bounded `agent_prompt_context_package.v1` payload plus a `reference_prompt` for the next model call.
- `contextlattice_agent_session rollup` and `contextlattice_agent_session context-package` expose the same flow to local agents.
- `contextlattice_agent_runtime_doctor` checks installed wrappers, Codex hooks, profile contracts, and gateway health.
- `contextlattice_skills_index search` gives agents capability discovery without loading every skill into startup context.

## Updated

- Agent runtime proof now validates the context-package phase and runtime-visible rollup contracts.
- Agent Radar surfaces rollup confidence, prompt package readiness, returned sources, and missing evidence.
- Public overview, CLI, wiki, integration, installation, premium, and copy-ready agent templates now describe session context packages as a core agent workflow.
