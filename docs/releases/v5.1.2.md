# ContextLattice v5.1.2: Cold Starts, Clean Proof.

Public unsigned technical preview. Includes the input-bound summaries, proof
packets and safe resume changes in [5.1.0](v5.1.0.md), plus the portable installer
corrections in [5.1.1](v5.1.1.md). The CLI remains the primary interface.

The full release audit exposed a cold-start test contaminated by the process-wide
Qdrant dimension cache when a mock listener reused an address. The fixture now
seeds that contamination deterministically, isolates only its own cache key, and
requires an actual owner probe. Disabled auto-create still forbids creation;
enabled auto-create must still use the observed embedding dimension. Production
caching and collection policy are unchanged.

The earlier public installer attempts stopped before publication. Their tags
remain unchanged; this patch carries the tested correction through the same
source, native package, downloaded-byte and promotion gates. No failed gate was
removed or replaced with a retry-until-green policy.

Preserve settings and persistent data during upgrade. Commercial artifacts remain
on their separately verified release pending their own final gates. This release
grants no new automation authority, changes no consent or license boundary, and
makes no independent efficacy, causal token-savings or billing claim. The
derivation-state downgrade restrictions in the 5.1.0 notes continue to apply.
