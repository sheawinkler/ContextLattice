# ContextLattice v3.9.1

Release date: 2026-07-03

v3.9.1 packages the dashboard and public-surface polish that landed after v3.9.0. The memory API, adapter contract, and outcome telemetry model stay compatible; this patch makes the product easier to read, easier to trust, and less noisy when operators inspect a live local stack.

## Highlights

- Refines the dashboard visual system with higher-contrast content plates, calmer page titles, cleaner metric cards, and more disciplined small-card grids.
- Restores the public hero/agent-prompt surface and keeps the public site aligned with the installed product story.
- Brings the topic hierarchy and mind-map view back together so operators can see projects, topics, and subtopics without confusing source inventory for knowledge structure.
- Reworks Settings into a clearer operator panel with real local values, no placeholder agent/model defaults, and paid runtime-key issuance gated behind authenticated paid entitlement.
- Removes odd Strict Hot Path wording and keeps Python fallback state framed by the actual Go-first backend boundary.
- Adds Sentrux proxy coverage for the local dashboard quality endpoint path.
- Updates current-version docs and LLM guidance to name v3.9.1 as the public baseline.

## Compatibility

No migration is required from v3.9.0. This is a patch release for dashboard clarity, public guidance, and release-lane hygiene.
