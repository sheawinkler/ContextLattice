## General Project Note: How ContextLattice Works

ContextLattice is a local-first memory orchestration layer for apps and agents.

- All write/search requests enter through one orchestrator contract.
- Writes are validated, durably recorded, then fanned out asynchronously to specialized stores.
- Retrieval uses staged lanes:
  - fast lane for immediate response quality (`topic_rollups`, `qdrant`, `postgres_pgvector`)
  - deep async continuation for broader coverage (`mindsdb`, `mongo_raw`, `letta`, `memory_bank`)
- Runtime ownership is explicit:
  - Go handles primary ingress/orchestration
  - Rust handles retrieval/memory hot paths
  - Python remains as rollback/compatibility fallback
