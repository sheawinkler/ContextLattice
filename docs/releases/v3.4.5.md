# ContextLattice v3.4.5

Release focus: generalized source backfill into ContextLattice memory.

## Added

- `scripts/agent/source-backfill-memory` imports bounded records from files/directories, JSONL, JSON, CSV, SQLite, DuckDB, Parquet via DuckDB, and Postgres via optional `psycopg`.
- Global install exposes `contextlattice_source_backfill` for local agents and operators.
- Source backfill writes through the existing `/memory/write` contract and can optionally run graph edge repair after successful writes.

## Safety

- Dry-run is the default.
- Writes require `--write --confirm-write <project>`.
- Record count, row bytes, document bytes, total bytes, and structured-list items are capped.
- Secret-like fields are redacted by default unless `--allow-sensitive` is set.
- Optional DuckDB/Postgres adapters fail fast with installation guidance when their drivers are unavailable.

## Fixed

- `scripts/agent/memory-graph-quality` now returns structured per-project repair failures when a large backfill preflight times out instead of crashing with a traceback.
