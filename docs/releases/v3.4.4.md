# ContextLattice v3.4.4

Release focus: memory topology policy and partitioning visibility.

## Added

- `/telemetry/storage` now includes `memoryTopology`, a bounded contract describing the base default path, full backend fabric, write partition keys, read cluster keys, deployment profiles, and source-lane status.
- `scripts/agent/audit-memory-topology` validates the live topology surface, required clusters, partition keys, source lanes, and graph telemetry.
- Global install now exposes `contextlattice_memory_topology` for local agents and operators.

## Clarified

- `topic_rollups + qdrant` is the base default app path, not the whole backend.
- Full/operator stacks keep pgvector, Weaviate, raw ledger/Mongo, Letta, memory-bank/Shodh, MindsDB, Skills Index, local inference runtimes, graph edges, and observability as additive lanes.
- Hosted/container-constrained lite surfaces can remain topic-rollup-first while preserving the same agent contract.
