# ContextLattice v3.4.13

v3.4.13 adds the zero-friction agent adoption kit: one command to inspect, install, prove, package, and template ContextLattice for local agents and adjacent LLM apps.

## Highlights

- Added `scripts/agent/contextlattice-adopt` as the adoption front door.
- Added global `contextlattice_adopt` installer wiring for macOS/Linux and `contextlattice_adopt.cmd` for Windows.
- Added adoption-kit checks to `contextlattice_agent_runtime_doctor`, including matrix planning, portable pack dry-run, and profile-template smoke.
- Added portable no-secrets agent packs through `contextlattice_adopt export` and `contextlattice_adopt import`.
- Added `contextlattice_adopt profile-template` for custom CLI, desktop, web, MCP, HTTP, and repo-local agent surfaces.
- Updated public docs to route new users through `contextlattice_adopt status --pretty` before lower-level proof commands.
- Added a preflight boundary headroom regression so `agent_preflight_response.v1` does not land on the byte-limit edge after contract metadata and downstream serializer differences.

## Product Contract

The adoption kit does not replace the universal agent adapter. It packages the setup path around it:

1. `status` answers whether this machine/account can use ContextLattice now.
2. `install` wires global helpers and optional Codex hooks.
3. `proof` runs the cross-profile memory lifecycle proof.
4. `export/import` moves a no-secrets agent pack between machines/accounts.
5. `profile-template` generates instructions for new agent surfaces.
