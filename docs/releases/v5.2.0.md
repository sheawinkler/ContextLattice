# ContextLattice v5.2.0

Public unsigned technical preview. The CLI remains the primary interface.

## Decisions That Survive The Handoff

Decision continuity now carries applicability, acknowledgement and resume evidence
through the CLI and agent-session surfaces. Public owner-local sessions retain
their ownership boundary when historical rows or typed lifecycle events disagree.
Synthesis regression coverage exercises real owner corrections at the final
output boundary rather than only checking a prepared intermediate result.

## Updates Without Losing Your Workspace

The CLI update path checks release identity and artifact integrity before handing
off to the existing installer. Managed updates preserve configuration and durable
data. Installation remains local-first; public use requires no paid account.
No public update may silently replace a paid installation.

Active writable binds into install-local preserved data are refused before
snapshot/replacement, preventing loss of late acknowledged writes. Keep writers
stopped through the update. Failed native-tool compilation preserves the working
CLI rather than deleting it or writing a legacy wrapper through its aliases.

The Unix installer includes optional `--skip-agent-tools` and `--no-browser`
controls. Source-bound readiness and failed-launch recovery records distinguish
successful file replacement from a healthy running application.

## Evidence You Can Inspect

The [evidence-chain report](../evals/evidence-chain-2026-11.md) separates public
regression fixtures from maintainer-reported source qualification. Neither test
counts nor packaging checks establish independent agent-task efficacy or causal
inference savings. Native coverage and paid acceptance are qualified separately;
this release does not claim a new five-platform certification.

## Security And Release Integrity

The dashboard uses Next.js 16.4.5. Installer metadata, final-file SBOM bindings,
checksums and package-content checks retain exact artifact identities. The public
installer accepts its disabled compatibility status without accepting the
remaining paid-runtime markers.

Preserve backups before updating. A launch failure after file commit retains
recovery state; it is not reported as an automatic rollback of runtime writes.
