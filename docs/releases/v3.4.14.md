# ContextLattice v3.4.14

v3.4.14 adds objective hierarchy and lineage to the agent runtime path so ContextLattice can package the next model call with the project objective, topic/subtopic objective, session objective, subobjectives, evidence, and next action in one bounded contract.

## Highlights

- Added `objective_hierarchy` and `objective_lineage` to `objective_runtime_state.v1` and `policy_context_package.v1`.
- Added project, topic/subtopic, session, and optional subobjective capture to objective context writes.
- Added objective hierarchy/lineage propagation through preflight, `/memory/search`, `/memory/context-pack`, Dream Mode, session rollups, prompt context packages, run traces, and run cards.
- Added hierarchy-aware objective coherence signals to Run Advisor.
- Added terminal trace visibility for project primary objective, topic objective, session objective, and lineage drift.
- Added dashboard Agent Radar Objective Lineage visibility beside context, source coverage, graph/handoff, advisor, skills, and timeline evidence.
- Updated public agent templates to preserve objective hierarchy and lineage in downstream handoffs.

## Product Contract

Flat `mission`, `objective`, and `goal` remain supported for existing clients. New clients can read the structured hierarchy:

- `project.primary_objective`
- `topic.topic_path`, `topic.subtopic`, and `topic.objective`
- `session.session_id` and `session.objective`
- `subobjectives`
- `current.level` and `current.objective`

`objective_lineage.drift` reports alignment across project, topic, and session objectives. The payload is bounded by the shared agent output contract registry and is intended for prompt packaging, handoff, trace inspection, and dashboard visibility.
