# ContextLattice v3.4.12

v3.4.12 adds a bounded Run Advisor and graph quality audit surface so agents can see whether a run is ready for the next model call.

## Highlights

- Added the `run_advisor.v1` output contract for prompt quality, retrieval posture, continuation state, objective coherence, graph quality, and next actions.
- Added `scripts/agent/contextlattice-run-advisor` and global `contextlattice_run_advisor` for terminal guidance from either a query/context pack or an existing session trace.
- Attached Run Advisor output to `/memory/context-pack` responses and agent run traces.
- Added dashboard Agent Radar Run Advisor visibility beside context-package status, source coverage, graph touches, handoffs, checkpoints, skills, and timeline evidence.
- Added graph edge quality audit metadata to memory edge backfill so generated edges expose confidence posture, review recommendations, and inferred-candidate counts.
- Hardened Compose naming so local Ollama, Letta, Caddy, and standalone MCP proxy services use Compose-scoped names instead of global singleton container names.

## Product Contract

Run Advisor is a decision-support layer, not a hidden model judge. It summarizes whether the current context packet is prompt-ready, whether slow-source continuation should be watched, whether the objective matches the retrieved evidence, and whether graph evidence was sampled. The payload stays bounded by the shared agent output registry.
