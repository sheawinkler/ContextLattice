# ContextLattice v5.1.1: Portable Builds. Same Evidence Gates.

Public unsigned technical preview. Includes the input-bound summaries, proof
packets, safe resume and telemetry changes described in [5.1.0](v5.1.0.md).
The CLI remains the primary interface.

## Installer Corrections

- Anonymous public-image tooling captures the selected installed Docker context
  before using an empty, temporary credential configuration. Linux default,
  Docker Desktop and OrbStack contexts can use their local Unix sockets; remote
  endpoints, credential overrides and unreviewed image digests remain rejected.
- Generated root-level `dist/` and `out/` directories no longer make the source
  checkout appear dirty. They remain excluded from installer payloads, including
  force-tracked material. Tracked source changes and unrelated untracked files
  still fail the exact-source audit.
- The product-truth workflow covers these build inputs and the anonymous Docker
  isolation tests, alongside the existing native installer and final-byte audits.

The 5.1.0 public installer attempt stopped before publication. Its tag is unchanged;
this patch release carries the corrections rather than moving that tag or waiving
the failed checks.

Preserve existing settings and data volumes during upgrade. Commercial artifacts
remain on their separately verified release until their own final gates pass.
This release grants no new paid automation authority and makes no new efficacy,
causal token-savings or billing claim. The derivation-state downgrade restrictions
in the 5.1.0 notes continue to apply.
