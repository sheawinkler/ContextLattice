# ContextLattice v3.4.11

v3.4.11 makes agent run-shaping visible without exposing raw prompts or oversized event payloads.

## Highlights

- Added `GET /v1/agents/sessions/{session_id}/trace` with the `agent_run_trace.v1` output contract.
- Added `scripts/agent/agent-run-trace` and global `contextlattice_agent_trace` for terminal tree, JSON, and Markdown run-card exports.
- Added dashboard Agent Radar trace inspection for context-package status, source coverage, skills that may be helpful, graph touches, handoffs, checkpoints, and recent timeline events.
- Added live ASCII progress to `contextlattice_agent_adoption_proof --progress` while keeping proof JSON on stdout.
- Adoption proof cases now include trace export commands for every proved session.

## Product Contract

The trace is bounded by the shared agent output registry. It returns compact evidence about what shaped a run, not raw provider messages, tool-call payloads, secrets, or unbounded logs. The run card is meant to help an agent package a stronger follow-up prompt by carrying forward relevant facts, risks, next actions, source coverage, skill candidates, and handoff/checkpoint state.
