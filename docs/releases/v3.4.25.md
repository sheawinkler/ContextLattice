# ContextLattice v3.4.25

Release date: 2026-06-19

v3.4.25 modernizes the Go build surface to Go 1.26.4 and packages the public changes that landed after v3.4.24.

## Highlights

- Updated Go module directives for `services/gateway-go` and `services/orchestrator-go` to `go 1.26` with `toolchain go1.26.4`.
- Updated Go Docker builder images to exact `golang:1.26.4-alpine` and `golang:1.26.4-bookworm` tags.
- Kept hosted/Glama lite on the single-container, topic-rollups-only path while modernizing the builder used for that image.
- Preserved local Lite's Qdrant-first vector lane and pgvector-disabled default.
- Added Qdrant native vector fanout/writeback coverage for MCP/tool write surfaces and public Dream Mode persistence.
- Added the post-v3.4.24 public train: global agent helpers ported to Go, graph neighbors in context packs, Review Mode, Bash 3.2 hook guard, bounded agent output boundaries, and Qdrant first-class writeback closure.

## Product Contract

The Go upgrade is a build/runtime surface update, not a memory contract change:

- Agent-facing HTTP and CLI response contracts remain bounded by the agent output registry.
- Local Lite remains `topic_rollups + qdrant`.
- Hosted/Glama lite remains sidecar-free with `topic_rollups` only.
- pgvector remains supported for Full/operator SQL-co-located vector deployments.
