# ContextLattice v5.1.0: Keep The Work. Show The Evidence.

Public unsigned technical preview. The CLI remains the primary interface;
native plugins, HTTP, MCP and the dashboard are companion surfaces.

## What Changed

- Registered local summaries can bind to exact input events and content hashes.
  New context and synthesis delivery suppresses stale or unproven derivatives;
  ordinary citations remain independent. Explicit recomputation restores eligibility.
- Compact synthesis packets preserve decisive proof roles, counterevidence,
  uncertainty and exact reference handles. If essential proof cannot fit, they abstain.
- Resume respects explicit session selection and rejects ambiguous, foreign,
  duplicate, incomplete or stale implicit selections before output or cache updates.
- Token reporting distinguishes signed net impact, positive-only compression,
  modeled avoidance and observed provider usage. Missing observations stay unknown.
- Dashboard refresh distinguishes fetch attempts, successful fetches and source
  timestamps, with cancellation, visibility-aware polling and backoff.
- Lite includes persistent memory/state defaults, the output-contract registry,
  readiness checks and architecture-aware builds. Dashboard startup no longer
  uses destructive schema synchronization.
- The optional Hermes provider preserves parent/session lineage. Skill-bundle
  inspection validates bounded deterministic resources without executing them.
- Runtime and dependency hardening includes Node 24 and patched Go/Alpine packaging.

See [derived memory](../derived-memory.md), [compact packets and resume](../agent-packets.md),
[telemetry accounting](../telemetry-accounting.md) and [Lite migration](../huggingface-space-lite.md).

## Scope And Upgrade

Back up existing data and preserve memory, state, session and task volumes.
Verify the selected artifact's source identity, readiness, exact readback and
retrieval after installation. Changing a persistent root does not migrate old data.

Do not downgrade a corpus of registered derivatives to an unaware server and
assume freshness protection remains. Keep affected derivative paths excluded
from current retrieval until supported serving is restored or owners recompute them.
Historical reads and already-delivered packets are not retroactively revoked.

Commercial distribution remains on its separately verified release until new
commercial artifacts pass their own release gates. This public release does not
grant paid automation, change consent or installation binding, or alter plan prices.

These are engineering changes, not proof of independent task efficacy, universal
agent compatibility, causal token savings or reduced bills. Unsigned technical
preview status does not waive source, integrity, security or installed-artifact checks.
