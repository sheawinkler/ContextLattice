# ContextLattice v5.1.0: Keep the Work. Show the Evidence.

Release candidate. Publication remains gated on edition-specific installed proofs and security review.

## What Changes

- Lite stores authoritative memory and gateway state beneath its declared durable data root. Its image includes the output-contract registry and reports readiness separately from liveness.
- Dashboard startup no longer accepts destructive schema synchronization. Use the documented backup and migration rehearsal before applying a schema change.
- Token reporting separates signed net impact, positive-only compression, modeled avoidance, and observed provider usage. Missing observations remain unknown; an explicit zero remains a measured zero.
- Dashboard snapshots expose fetch attempts, successful fetches, and source timestamps separately. Manual refresh, stale-data handling, cancellation, visibility-aware polling, and backoff replace silent stale overwrites.
- The optional Hermes memory provider records scoped host-hook observations without pretending that a hook proves model consumption or independent task success. It does not replace an existing provider automatically.
- Native skill-bundle inspection validates bounded deterministic resources and their whole-bundle digest. Inspection does not execute code, grant permissions, or activate a skill.
- Temporal retrieval treats equivalent timestamp representations as the same instant while preserving ordinary-query scoring.
- Dependency updates are reviewed against the actual shipped consumers rather than treated as proof of compatibility by version number alone.
- Owned Node runtimes use Node 24.22.2 and npm 11.19.1. The runtime audit checks every container stage, including platform-qualified stages, instead of accepting an outdated final stage behind a current builder.

The CLI remains the primary general-purpose interface. Native plugins are optional host integrations; HTTP, MCP, and the dashboard remain companion surfaces.

## Start With The New Surfaces

See [skill resource bundles](../skill-resource-bundles.md) for the native `contextlattice_skills_index bundle-inspect` command, [Hermes integration](../../integrations/hermes-memory-provider/README.md) for provider setup and limitations, and [telemetry accounting](../telemetry-accounting.md) for metric definitions.

Public local mode remains account-free. Paid authorization, installation binding, and workspace boundaries remain enforced. No plan prices, feature entitlements, or automation consent requirements change in this release.

## Upgrade And Recovery

Back up existing memory, session, task, and dashboard data first. For an older Lite installation, follow the [migration inventory](../huggingface-space-lite.md) before replacing its container: adding a new durable root does not recover data left in an old ephemeral layer.

Preserve data volumes when replacing images. Verify source identity, readiness, exact readback, and retrieval afterward. A rollback rehearsal must use compatible state and identified prior artifacts, not delete the new state to make a check pass.

These changes improve observable engineering behavior. They do not establish universal agent compatibility, independent task efficacy, causal token or bill savings, or a successful customer purchase.
