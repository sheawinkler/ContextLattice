# ContextLattice Eval Ledgers

These machine-readable ledgers record release-sensitive memory, retrieval, agent, and orchestration evaluations. Each ledger separates observed evidence from interpretation and includes reproduction commands, costs, failures, and holdout scope.

Start with [Evidence you can inspect](evidence-chain-2026-11.md): a dated guide to
the proof chain, recorded results, public reproduction paths, and claims that the
evidence does not establish. Its [JSON snapshot](evidence-chain-2026-11.json)
keeps measurement units and limitations alongside the numbers.

Public ledgers must not contain secrets, private capability names, local absolute paths, or raw user memory.
