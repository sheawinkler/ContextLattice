CLI

Install, launch, and validate Context Lattice from terminal in minutes.

Use these commands as the canonical local flow for public and premium lanes, including prompt-ready context compilation before expensive agent reasoning.

Install

Clone + bootstrap

git clone https://github.com/sheawinkler/ContextLattice.git
cd ContextLattice
BOOTSTRAP=1 scripts/first_run.sh
Launch

Guided quickstart

gmake quickstart

`quickstart` now shows resource guidance and lets users choose the best profile for their machine.

Monitor

Health and dashboard checks

gmake monitor-open
# or terminal-only checks
gmake monitor-check
Write/search smoke

ORCH_KEY="$(awk -F= '/^CONTEXTLATTICE_ORCHESTRATOR_API_KEY=/{print substr($0,index($0,"=")+1)}' .env)"

Context compiler

Build the next prompt packet from memory

contextlattice_pack "ship release notes without missing prior decisions" --project contextlattice --pretty

curl -fsS -H "content-type: application/json" -H "x-api-key: ${ORCH_KEY}" \
  -d '{"project":"contextlattice","query":"ship release notes without missing prior decisions","retrieval_mode":"balanced"}' \
  http://127.0.0.1:8075/memory/context-pack | jq '.reference_prompt'

The compiler returns ranked evidence, files to inspect, checks, risks, source coverage, and a bounded reference_prompt that can be handed to Codex, Claude Code, MCP hosts, or a custom LLM app.

Agent runtime contract

Give every agent the same memory spine

# one-command live proof
contextlattice_agent_runtime_proof --pretty

# start or recover a ContextLattice-owned session
BOOTSTRAP_JSON="$(contextlattice_agent_adapter bootstrap --agent codex --project contextlattice)"
SESSION_ID="$(printf '%s' "$BOOTSTRAP_JSON" | python3 -c 'import json,sys; print(json.load(sys.stdin)["session_id"])')"

# retrieve bounded context against that session
contextlattice_agent_adapter context-pack --agent codex --project contextlattice --session-id "$SESSION_ID" --pretty

# write durable progress and handoff state
contextlattice_agent_adapter checkpoint --agent codex --project contextlattice --session-id "$SESSION_ID" --content "checkpoint summary"
contextlattice_agent_adapter handoff --agent codex --project contextlattice --session-id "$SESSION_ID" --summary "handoff summary"
contextlattice_agent_adapter complete --agent codex --project contextlattice --session-id "$SESSION_ID" --summary "completed"

# package the session for the next model call
contextlattice_agent_session rollup --session-id "$SESSION_ID" --pretty
contextlattice_agent_session context-package --session-id "$SESSION_ID" --pretty

Use profiles such as codex, claude-code, opencode, hermes-agent, chatgpt-web, and claude-web to keep handoffs consistent across runtimes.

Session hygiene

Review stale audit sessions before cleanup

# dry-run: list only known stale objective-runtime audit/preflight sessions
scripts/agent/contextlattice-session sweep-stale-audits --all-projects --pretty

# confirmed cleanup after review
scripts/agent/contextlattice-session sweep-stale-audits --all-projects --confirm --pretty

Normal users do not need this during everyday memory work. It is an operator safety valve for stale audit/preflight sessions, and dry-run is the default.
