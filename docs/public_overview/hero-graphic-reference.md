# Hero Graphic Reference

## Purpose
The hero visual depicts ContextLattice as a live context fabric: distributed events flow in from many shapes and trajectories, then converge into a dynamic source core where context is merged, prioritized, and made actionable.

## Visual Semantics
- Grid + frames: bounded operating field (structured runtime, not chaos).
- Lanes (cool/warm/weave/surge): heterogeneous context streams with distinct speed and confidence profiles.
- Moving particles (dots/squares/triangles/hex): different payload classes (signals, metadata, traces, and compressed context).
- Source core (orb + rings + orbiting micro-orbs): active merge engine with continuous ranking and reweighting.

## Lane Behavior
- Field lanes: stable backbone streams with subtle curvature drift.
- Weave lanes: non-linear correlated context (cross-source linkage paths).
- Serpentine lanes: high-variability inputs that still preserve directional convergence.
- Surge lanes: burst arrivals that accelerate into the core.

## Orb Behavior
- Primary orb: consensus sink where multi-lane context converges.
- Orbiting micro-orbs: local reweighting loops that capture short-lived shifts before folding them into the core state.
- Aura ring: confidence and influence field expanding and contracting with runtime pressure.

## Anomaly Signal (Red)
- Cadence: every `5 + 1.5*x` seconds, where `x` is a random integer in `[0, 50]`.
- Motion: enters through the same ingress fabric, reaches the core, then deflects to the right and fades into the abyss.
- Meaning: policy-rejected or conflict-routed context that is observed, evaluated, and intentionally ejected.

## Variants
- `index.html` (warm orb): amber-pink core emphasis for adaptive, human-guided memory evolution.
- `index-orb-white.html` (white orb): neutral HDR-white core emphasis for strict signal/precision presentation.

## Accessibility
- If reduced motion is enabled (`prefers-reduced-motion: reduce`), anomaly triggers are suppressed.
- All movement is decorative and does not hide critical product information.
