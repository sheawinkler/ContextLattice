DNS checklist

What to point where

  • contextlattice.io -> static docs host (GitHub Pages today)
  • app.contextlattice.io -> dashboard host (Next.js + billing APIs)
  • api.contextlattice.io -> orchestrator ingress for agent/runtime calls
Launch posture

Near-term vs later

  • Now: app domain handles auth, billing, entitlement state, and paid console.
  • Later: optionally serve the lightweight app/lite runtime surface from the same domain.
  • Always: keep webhook endpoints on app domain for deterministic provider configuration.
App domain split reduces ops confusion during paid launch. Use premium launch gates before enabling production entitlements.
